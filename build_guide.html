Laptop Build Guide

A map of the whole process, from BIOS settings to a fully tuned install. Each step links to the detailed Dortania documentation, which is the authoritative source.

This guide is an overview, not a replacement for the Dortania OpenCore Install Guide. Keep it open alongside.

1. Prepare

Before touching anything, know exactly what's inside your laptop. Boot Windows or a Linux live USB and note:

  • CPU generation: decides which Dortania config section you follow. 8th–10th gen Intel is the sweet spot.
  • iGPU: you need its device ID for the framebuffer patch.
  • Wi-Fi card: Broadcom, Intel, or something to replace. See the Component Checker.
  • Audio codec: you'll need it to choose an AppleALC layout-id.
  • Trackpad bus: PS/2, I2C or SMBus. This decides which Voodoo kext you use.
  • NVMe SSD model: some drives (notably some Samsung OEM ones) cause trouble.

You'll also need a USB stick of 16 GB or more, and a way to back up your current system.

2. BIOS settings

Names differ between vendors, but look for these:

  • Disable: Secure Boot, Fast Boot, CSM/Legacy boot, Intel SGX, Intel Platform Trust,VT-d (or enable DisableIoMapper), serial/parallel ports, and any discrete NVIDIA GPU you can switch off.
  • Enable: UEFI boot, VT-x, Above 4G decoding (if present), XHCI hand-off, and AHCI mode for SATA.
  • DVMT pre-allocated memory: 64 MB if the option exists. If not, you'll patch around it in the framebuffer.
  • CFG Lock: disable it if you can (sometimes only through a modified BIOS variable). Otherwise enable AppleXcpmCfgLock in your config.

3. Create the USB installer

  1. From macOS, download the full installer from the App Store and use createinstallmedia.
  2. From Windows or Linux, use OpenCore's macrecovery.py to fetch the recovery image, then copy it to a FAT32 USB. This needs an internet connection during install, so pick a machine with Ethernet or a supported Wi-Fi card.

Details: Creating the USB.

4. Build the EFI

The EFI folder is your Hackintosh. Build it yourself rather than downloading a random one; you'll understand and fix it far more easily.

  1. Download the latest OpenCorePkg release and copy the EFI folder structure.
  2. Add firmware drivers: OpenRuntime.efi and HfsPlus.efi (or OpenHfsPlus.efi).
  3. Add kexts: Lilu, VirtualSMC (+ SMCBatteryManager), WhateverGreen, AppleALC, your trackpad/keyboard kexts, Wi-Fi/Bluetooth kexts and NVMeFix. Order matters: Lilu first, plugins after the kexts they extend.
  4. Generate ACPI patches with SSDTTime. Laptops commonly need SSDT-PLUG, SSDT-EC-USBX, SSDT-PNLF (backlight), SSDT-AWAC/RTC0 and SSDT-XOSI/GPI0 for I2C trackpads.
  5. Copy Sample.plist to config.plist, run OC Snapshot in ProperTree, then follow your CPU generation's laptop section line by line.
  6. Pick a SMBIOS close to your hardware (e.g. MacBookPro15,2 for 8th gen U-series) and generate serials with GenSMBIOS.

Keep the verbose boot argument -v and debug=0x100 keepsyms=1 while setting up. A frozen Apple logo tells you nothing; verbose text tells you where it stopped.

5. Install macOS

  1. Boot the USB from the firmware boot menu, then pick the installer in the OpenCore picker.
  2. In Disk Utility, choose Show All Devices and erase the target drive as APFS with a GUID Partition Map.
  3. Run the installer. It reboots several times; pick the macOS Installer entry each time until it's gone.

If it hangs, note the last lines on screen and check Troubleshooting.

6. Post-install

  • Boot without the USB: mount the internal EFI partition (e.g. with MountEFI) and copy your EFI folder over.
  • USB mapping: map ports with USBToolBox and drop the port-limit quirk.
  • Audio: try AppleALC layout-ids for your codec until speakers, headphones and mic all work.
  • Sleep & battery: check that the lid sleeps and wakes, and battery percentage updates. Disable hibernation with sudo pmset -a hibernatemode 0.
  • Brightness keys: map them with BrightnessKeys.kext and SSDT-PNLF.
  • Clean up: remove -v and debug flags, and hide auxiliary entries in the picker.
