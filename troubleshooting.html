Troubleshooting

The most common laptop problems and where to start fixing them. Always boot with -v so you can see where things stop.

Booting the installer

▶Stuck at EndRandomSeed or “Security Violation”
  • Make sure HfsPlus.efi (or OpenHfsPlus.efi) and OpenRuntime.efi are in EFI/OC/Drivers and listed in UEFI → Drivers.
  • For a recovery-based installer, set Misc → Security → DmgLoading to Signed and SecureBootModel to Disabled while installing.
  • Run your config through OpenCore's ocvalidate tool to catch typos and missing keys.
▶Stuck at [EB|#LOG:EXITBS:START]
  • This is almost always a Booter quirks problem. Recheck every quirk against the Dortania page for your exact CPU generation.
  • Confirm the BIOS settings: CSM off, Secure Boot off, VT-d off (or DisableIoMapper on).
  • Check you're using the correct SSDTs. A missing or wrong SSDT-EC or SSDT-PLUG can also stall here.
▶Prohibited sign or “Waiting for Root Device”
  • Usually USB: macOS can't see the installer. Try a USB 2.0 port, and map your ports with USBToolBox.
  • Set SATA to AHCI (not RAID/Intel RST) in the BIOS.
  • Make sure XHCI hand-off is enabled in the BIOS.
▶Kernel panic mentioning CPU power management or CFG Lock

Your firmware has CFG Lock enabled. Disable it in the BIOS (sometimes only possible by editing a hidden BIOS variable), or enable Kernel → Quirks → AppleXcpmCfgLock.

Graphics & display

▶Black screen after the verbose text ends
  • Check AAPL,ig-platform-id and device-id under DeviceProperties match the recommended laptop values for your iGPU.
  • If your BIOS has only 32 MB DVMT, add the framebuffer-stolenmem and framebuffer-fbmem patches.
  • On some 8th gen and newer laptops the backlight stays off. Try the -igfxblr boot argument.
  • Disable any NVIDIA dGPU with an SSDT (SSDT-dGPU-Off) so macOS doesn't try to use it.
▶No brightness slider or brightness keys

Add SSDT-PNLF (generate it with SSDTTime) for the slider, and BrightnessKeys.kext for the function keys.

Wireless, audio & input

▶Wi-Fi doesn't work
  • Intel cards: use AirportItlwm for the version of macOS you're running (each macOS version has its own build), or itlwm with the HeliPort app.
  • Broadcom cards: on macOS 14 Sonoma and later, Apple removed the drivers for older Broadcom chips. You'll need OpenCore Legacy Patcher root patches.
  • Realtek / Qualcomm / MediaTek: unsupported. Replace the card if it's an M.2 module.
▶Bluetooth doesn't turn on

For Intel Bluetooth on Monterey and later, use IntelBluetoothFirmware together with BlueToolFixup (from BrcmPatchRAM). For Broadcom, use BrcmPatchRAM3, BrcmFirmwareData and BlueToolFixup.

▶No sound
  • Find your codec's supported layout-ids in the AppleALC documentation.
  • Test quickly with the alcid=XX boot argument, then make the working value permanent in DeviceProperties.
  • If speakers work but headphones don't (or vice versa), try other layout-ids before anything else.
▶Trackpad doesn't work or has no gestures
  • PS/2: VoodooPS2Controller.
  • I2C: VoodooI2C + VoodooI2CHID, usually with an SSDT-GPI0 or SSDT-XOSI patch so the controller is enabled.
  • Synaptics SMBus (many ThinkPads): VoodooRMI on top of VoodooPS2 for full gestures.

Power, sleep & battery

▶Wakes immediately after sleep, or won't wake
  • Finish USB mapping first: unmapped ports are the #1 cause of instant wake.
  • Disable hibernation: sudo pmset -a hibernatemode 0, plus Power Nap and “Wake for network access”.
  • Run pmset -g log | grep -i wake to see what's waking the machine.
  • Some laptops (e.g. later ThinkPads) default to S0 Modern Standby. Switch the BIOS sleep state to “Linux”/S3 if it's offered.
▶Battery percentage missing or stuck

Add SMCBatteryManager (part of VirtualSMC). If it still doesn't update, your embedded controller probably uses multi-byte fields; add ECEnabler.kext instead of hand-patching ACPI.

Apple services

▶iMessage, FaceTime or iCloud won't sign in
  • Generate a unique serial with GenSMBIOS and check on Apple's coverage site that it's not already in use.
  • Make sure your network interface is en0 and marked as built-in.
  • Set ROM under PlatformInfo → Generic to your network card's MAC address.
